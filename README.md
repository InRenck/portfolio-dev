Bem-vindo ao repositório do meu portfólio profissional. Este projeto foi construído do zero com foco em **alta performance**, **acessibilidade** e **arquitetura limpa**.

## 🚀 Tecnologias Utilizadas (Stack)

Foi desenvolvido utilizando o ecossistema moderno do React, garantindo tipagem estática, build ultrarrápido e estilização utilitária escalável:

- **[React 18](https://react.dev/)** - Biblioteca de UI
- **[TypeScript](https://www.typescriptlang.org/)** - Tipagem estática e segurança de código
- **[Vite](https://vitejs.dev/)** - Bundler de altíssimo desempenho
- **[Tailwind CSS](https://tailwindcss.com/)** - Estilização ágil e responsiva
- **[Node.js](https://nodejs.org/)** - Ambiente de execução

## 🧠 Arquitetura e Decisões Técnicas

- **Separação de Preocupações:** Os dados do portfólio (`src/data`) são estritamente isolados da camada visual (`src/components`), permitindo atualizações de conteúdo sem risco de quebrar a interface.
- **Tipagem Rigorosa:** Uso de `Interfaces` do TypeScript para garantir contratos de dados consistentes em toda a aplicação.
- **Color Blocking & UI/UX:** Design construído com contraste estratégico (modo claro/escuro intercalado) para guiar a leitura do recrutador, mantendo fluidez e responsividade nativa.
- **Performance (Lighthouse):** Arquitetura leve desenhada para atingir pontuações máximas em métricas de Web Vitals, SEO e Acessibilidade.
